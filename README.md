# 🌍 Car GameWorld
**Real-Time Procedural World Generation Driving Game**

[![Three.js](https://img.shields.io/badge/Three.js-black?style=for-the-badge&logo=three.js&logoColor=white)](https://threejs.org/)
[![Vite](https://img.shields.io/badge/Vite-B73BFE?style=for-the-badge&logo=vite&logoColor=FFD62E)](https://vitejs.dev/)

เกมขับรถ 3D ที่สร้างโลกเสมือนจริงขึ้นมาแบบ Real-Time จากข้อมูลแผนที่ **OpenStreetMap** และ **Open Topo Data** สามารถเลือกสถานที่ใดก็ได้บนโลกผ่านแผนที่ Interactive เพื่อเข้าไปขับรถสำรวจถนน ภูเขา อาคาร และแม่น้ำได้อย่างอิสระ!

## ✨ ฟีเจอร์หลัก (Key Features)

- 🗺️ **Procedural Generation:** สร้างตึก ถนน ต้นไม้ และแม่น้ำแบบสดๆ จากข้อมูลจริงของโลก (OSM)
- ⛰️ **Real Elevation (DEM):** ภูมิประเทศมีความสูงต่ำสมจริง อ้างอิงจากข้อมูลระดับน้ำทะเล (SRTM)
- 🚗 **Raycast Vehicle Physics:** ระบบฟิสิกส์รถยนต์ที่สมจริง รองรับระบบโช้ค การเบรก แรงเสียดทาน และเบรคมือ (Cannon-es)
- 🌍 **Interactive Map Picker:** เลื่อนแผนที่จิ้มปักหมุดจุดเริ่มต้นได้ทั่วโลกด้วย Leaflet.js
- ⚡ **Chunk Streaming System:** โหลดเฉพาะส่วนที่ผู้เล่นมองเห็น (Chunk) ช่วยลดการใช้ RAM และเพิ่ม FPS
- 🧱 **ชนตึกได้จริง:** ตึกทุกหลังมีกล่องชน (collider) หมุนตามแนวผนัง รถขับทะลุตึกไม่ได้แล้ว
- 🔊 **เสียงเครื่องยนต์:** สังเคราะห์ด้วย Web Audio (ไม่ใช้ไฟล์เสียง) รอบเครื่องขึ้นลงตามความเร็วและเกียร์ 5 สปีด
- 🎮 **จอยเกมและจอสัมผัส:** รองรับ Gamepad (Xbox/PS) และมีปุ่มบนจอให้อัตโนมัติเมื่อเล่นบนมือถือ/แท็บเล็ต
- 💾 **จำค่าตั้งค่า:** ระยะมองเห็น คุณภาพกราฟิก เงา ต้นไม้ เสียง และกลางวัน-กลางคืน ถูกบันทึกไว้ในเบราว์เซอร์
- 🏁 **โหมดเช็กพอยต์:** สุ่มจุดหมายบนถนนจริงห่าง 150–450 ม. มีลำแสงสีเหลืองในฉาก จุดบนมินิแมพ และลูกศรชี้ทางบน HUD พร้อมจับเวลาและนับจำนวนที่ผ่าน
- 🏙️ **เมืองสมจริงขึ้น:** ตึกมีหน้าต่างทุกชั้น (กลางคืนไฟติดบางห้อง) ความสูงตึกที่ไม่มีข้อมูลสุ่มจาก id ให้หลากหลาย 2–5 ชั้น (บ้านเดี่ยว 2 ชั้น โรงรถ 1 ชั้น) ถนนสายหลักมีเส้นขอบทาง เส้นกลางถนนสีเหลือง หรือเส้นประแบ่งเลนถ้าเดินรถทางเดียว ถนนซอยมีเส้นประกลางถนน และมีเสาไฟริมถนนทุก 35 ม. ที่สว่างตอนกลางคืน
- 🚶 **ทางเท้าและทางม้าลาย:** ทางเท้า 2 ม. ตามแท็ก `sidewalk` ใน OSM ถ้าไม่มีแท็กจะมีเฉพาะถนนในเมือง (primary/secondary/tertiary) ถนนซอยในหมู่บ้านและถนนผ่านทุ่งไม่มีทางเท้า ทางแยกจริง (ถนน 3 แขนขึ้นไป) ที่มีทางเท้ามีทางม้าลายทุกแขน และเส้นจราจรกับทางเท้าจะหยุดก่อนถึงทางแยก ไม่พาดทับถนนอีกเส้น
- 🏠 **หลังคาจั่ว:** บ้าน (house, detached, bungalow ฯลฯ) ขนาดไม่เกิน 400 ตร.ม. ที่เป็นทรงสี่เหลี่ยม มีหลังคาจั่วสีกระเบื้อง สันหลังคาวิ่งตามผนังด้านยาว
- 💥 **เสาไฟชนได้:** รถชนเสาไฟริมถนนแล้วหยุด ไม่ทะลุ
- 🚦 **สัญญาณไฟจราจร:** อ่านจุด `highway=traffic_signals` จาก OSM วางเสาไฟฝั่งที่รถวิ่งในประเทศนั้น (ซ้าย: ไทย ญี่ปุ่น อังกฤษ ฯลฯ / ขวา: ที่อื่น) หันหน้าหารถที่วิ่งเข้ามา รอบไฟ 24 วิ ถนนที่ตัดกันไม่เขียวพร้อมกัน
- 🚗 **รถ NPC:** รถสูงสุด 12 คันวิ่งตามถนนจริงรอบตัวเรา ชิดเลนตามประเทศ ความเร็วตามประเภทถนน หยุดไฟแดง เว้นระยะคันหน้าและเบรกให้รถเรา เลี้ยวต่อที่ทางแยก ชนได้ (ปิดได้ในตั้งค่า)
- 🧱 **ตึกรูปตัว L/U ชนได้ตรงรูป:** ตึกที่ไม่ใช่สี่เหลี่ยมถูกแบ่งเป็นแถบกว้าง 2 ม. ตามรูปจริง มุมด้านในของตัว L หรือลานกลางตึกขับเข้าไปได้
- 🏆 **สถิติเช็กพอยต์:** เก็บเพซดีที่สุด (นาที/กม.) และจำนวนเช็กพอยต์รวมแยกตามสถานที่ ขึ้น "สถิติใหม่!" เมื่อทำลายสถิติ
- 🌗 **กลางวัน-กลางคืน:** 1 วันในเกม = 10 นาทีจริง ดวงอาทิตย์ขึ้นตก ท้องฟ้าเปลี่ยนสี และไฟหน้ารถติดเองตอนมืด (ปิดได้ในตั้งค่าเพื่อให้เป็นเที่ยงตลอด)

## 🚀 การติดตั้งและใช้งาน (Installation)

โปรเจกต์นี้ทำงานด้วย Node.js และแพ็กเกจจัดการโมดูลแบบ Vite

### ข้อกำหนดระบบ
- **Node.js** (v16+)
- **Git**

### ขั้นตอนติดตั้ง
1. โคลน Repository นี้:
   ```bash
   git clone https://github.com/yourusername/car_gameworld.git
   cd car_gameworld
   ```
2. ติดตั้ง Dependencies (Three.js, Cannon-es, Leaflet):
   ```bash
   npm install
   ```
3. เปิด Development Server:
   ```bash
   npm run dev
   ```
   > 🌐 **เปิด Browser ไปที่:** `http://localhost:3000`
4. (ไม่บังคับ) ตรวจสอบว่าระบบยังทำงานถูกต้อง โดยไม่ต้องเปิด Browser:
   ```bash
   npm run verify              # เรขาคณิต ทิศทาง ฟิสิกส์รถ ตารางความสูง (ออฟไลน์)
   npm run verify -- --online  # รวมการดึงข้อมูล OSM จริงที่บางแสนและโตเกียว
   ```

## 🎮 วิธีการเล่น (How to Play)

### 1. เลือกสถานที่
ในหน้าแรกคุณสามารถ **ค้นหาชื่อเมือง** หรือ **จิ้มบนแผนที่แบบ Interactive** เพื่อปักหมุดจุดเริ่มต้น หากต้องการทดสอบอย่างรวดเร็ว สามารถกดเลือกจาก "สถานที่แนะนำ" (Presets) ได้ทันที จากนั้นกดปุ่ม **🚗 Start Driving**

### 2. ปุ่มควบคุม
| ปุ่ม | การกระทำ |
|:---:|:---|
| `W` / `↑` | เร่งเครื่อง (คันเร่ง) |
| `S` / `↓` | ถอยหลัง / เบรก |
| `A` / `D` | เลี้ยวซ้าย / ขวา |
| `Space` | เบรคมือ (Handbrake / ดริฟท์) |
| `C` | เปลี่ยนมุมกล้อง (Third-Person, Bird's Eye, Hood) |
| `R` | รีเซ็ตตำแหน่งรถ (ในกรณีที่พลิกคว่ำหรือติดหล่ม) |
| `ESC` | เปิดหน้าต่างตั้งค่ากราฟิก (Settings) |

**โหมดเช็กพอยต์:** เริ่มอัตโนมัติเมื่อเข้าเกม ขับตามลูกศรสีเหลืองด้านบนจอไปยังลำแสงสีเหลือง เข้าใกล้ภายใน 12 ม. ถือว่าผ่าน แล้วจุดถัดไปจะสุ่มขึ้นมาใหม่ นาฬิกาเวลาในเกมแสดงที่มุมขวาบน

**จอยเกม (Gamepad):** เสียบแล้วกดปุ่มใดก็ได้หนึ่งครั้งเพื่อให้เบราว์เซอร์รู้จัก

| ปุ่มจอย | การกระทำ |
|:---:|:---|
| `RT` / `A` / D-pad ขึ้น | เร่ง |
| `LT` / `B` / D-pad ลง | เบรก / ถอย |
| สติ๊กซ้าย / D-pad ซ้าย-ขวา | เลี้ยว |
| `X` | เบรคมือ |
| `Y` | รีเซ็ตรถ |
| `Back` / `View` | เปลี่ยนมุมกล้อง |
| `Start` / `Menu` | ตั้งค่า |

**มือถือ/แท็บเล็ต:** ปุ่ม ◀ ▶ (เลี้ยว) อยู่ซ้ายล่าง, ▲ ▼ ⏸ (เร่ง เบรก เบรคมือ) อยู่ขวาล่าง, R 📷 ⚙ อยู่ตรงกลาง

## 🏗️ สถาปัตยกรรม (Architecture)

1. **OSM Fetcher & Elevation Fetcher:** 
   ดึงข้อมูลรอบจุดเริ่มต้นรัศมี 600 ม. จาก `OSM API` ครั้งเดียว เมื่อขับออกนอกพื้นที่จะดาวน์โหลดพื้นที่ 1.2 กม. ใหม่ทั้งก้อน (chunk ที่ต้องการพื้นที่เดียวกันรอ request เดียวกัน) แทนการยิงทีละ chunk จำไว้ 6 พื้นที่ล่าสุด สำรองด้วยการโหลดทีละ chunk และ `Overpass API` ส่วนความสูงดึงจาก `Open Topo Data` แบบ Asynchronous
2. **Chunk Manager:** 
   ทำงานร่วมกับ `WorldBuilder` เพื่อ Generate วัตถุแบบ Grid 200x200m และทยอยโหลด/ลบทิ้ง (Dispose) เพื่อจัดการ Memory
3. **Vehicle & Camera Controller:** 
   แปลง Input (คีย์บอร์ด จอย หรือปุ่มสัมผัส ซึ่ง `InputManager` แปลงเป็นปุ่มเดียวกันหมด) เป็นค่าแรงทางฟิสิกส์ให้ `Cannon-es` และสั่งกล้องให้ติดตามรถแบบ Interpolation อย่างนุ่มนวล
4. **Physics World:** 
   พื้นเป็น `Heightfield` ต่อ chunk และตึกทั้ง chunk รวมเป็น static body เดียวที่มีกล่องหลายอัน ถูกลบออกพร้อม chunk (เสาไฟและเสาไฟจราจรก็เช่นกัน) รถ NPC เป็น kinematic body
5. **การตัดถนนตาม chunk:** ถนน แม่น้ำ เส้นจราจร และทางเท้า วาดเฉพาะส่วนที่อยู่ใน chunk (เกินขอบ 1.5 ม. กันรอยต่อ) ทะเลสาบวาดโดย chunk ที่มีจุดกึ่งกลางเท่านั้น

### โครงสร้างไฟล์
```
src/
  core/      Game (ลูปหลัก), InputManager (คีย์บอร์ด/จอย/สัมผัส), Mission (โหมดเช็กพอยต์)
  data/      OSMFetcher, ElevationFetcher, ElevationField, CacheManager (IndexedDB), GeoUtils
  world/     ChunkManager, Chunk, WorldBuilder, Terrain/Road/Building/Water generators, VegetationPlacer,
             StreetLamps, NightLights (หน้าต่าง/ไฟถนนตอนกลางคืน), DayNight, Polyline (ตัด/วัดเส้น),
             TrafficLights (สัญญาณไฟ), Traffic (รถ NPC)
  data/      ... DrivingSide (ประเทศไหนขับชิดซ้าย)
  vehicle/   CarController (ฟิสิกส์), CarModel, CameraController, EngineSound
  ui/        LocationPicker, LoadingScreen, HUD, Minimap, SettingsPanel
scripts/
  verify-world.mjs   ชุดตรวจสอบอัตโนมัติ (npm run verify)
```

## 🛠️ การตั้งค่าเพิ่มเติม (Configuration)

หากต้องการปรับจูนตัวแปรของเกม (เช่น ความแรงรถ ขนาดของโลก ฯลฯ) สามารถเข้าไปแก้ไขได้ที่ `src/config.js`
- `CHUNK_SIZE`: ขนาดของแต่ละพื้นที่ (Default: 200 เมตร)
- `VIEW_DISTANCE`: ระยะสายตา (Default: 3 Chunks = รัศมี 600 เมตร)
- `CAR_MAX_FORCE`: แรงบิดของเครื่องยนต์

## 🐞 บั๊กที่แก้แล้ว (รอบล่าสุด)

- ถนนยาววาดซ้ำทุก chunk และความสูงนอก chunk ผิด ทำให้ถนนซ้อนกันกระพริบบนเนิน และสิ้นเปลืองสามเหลี่ยม → ตัดถนนตาม chunk (สามเหลี่ยมในฉากลดจาก ~114k เหลือ ~79k ทั้งที่มีของเพิ่ม)
- ทะเลสาบวาดหลายรอบที่ระดับน้ำต่างกันในแต่ละ chunk → วาดครั้งเดียว แม่น้ำไหลตามความสูงพื้น
- กด Space ในช่องค้นหาสถานที่ไม่ได้ (เกมกิน Space ทั้งหน้า) → ไม่รับปุ่มที่กดในช่องกรอก
- เช็กพอยต์ค้างอยู่ไกลหลังรีเซ็ต/ย้ายรถ → สุ่มจุดใหม่เมื่อไกลเกิน 1.35 กม.
- ตึกทุกหลังเป็นสีเทาอมน้ำเงินตอนกลางวัน (ดวงอาทิตย์ตรงหัว ผนังได้แต่แสงรอบข้างสีฟ้า) → ทางเดินดวงอาทิตย์เอียง (~55° ตอนเที่ยง) และแสงรอบข้างสีขาว
- เสาไฟ เสาไฟจราจร และรถ NPC เป็นสีดำ (วัสดุโลหะแต่ไม่มีอะไรให้สะท้อน) → ลด metalness
- ทางเท้าสีเทามีทุกถนนแม้แต่ซอยกลางทุ่ง → ใช้แท็ก OSM หรือเฉพาะถนนในเมือง
- หน้าต่างเป็นช่องดำใหญ่ → หน้าต่างเล็กลง กระจกสีอ่อน มีกรอบ
